# Retraite Sereine

> Le projet va afficher les différents EPHAD présent dans la region parisienne et ces alentours.

---

## 🧐 À propos du projet
Donc c'est un projet scolaire ou l'on devait recupérer une API et l'afficher dans notre page web d'une manière qu'on avait décidé.Des bonus étaient disponibles pour enrichir notre projet avec certaines fonctionnalités supplémentaires.

## ✨ Fonctionnalités
* **Fonctionnalité 1 :** Affichage dynamique des différents EHPAD en forme de cartes
* **Fonctionnalité 2 :** Search Barre fonctionnel avec un filtrage de si on met que le code postal ou bien le nom celui-ci trouve quand même
* **Fonctionnalité 3 :** On peut afficher plus de résidences avec le bouton "Voir plus de résidences" par 3
